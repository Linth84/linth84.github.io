WHAT WAS ADDED
--------------
1. public/portfolio-card.png
   - Exact 1200 x 630 capture of the real portfolio hero.

2. index.html
   - Descriptive <title> and meta description.

5. src/App.tsx
   - Route-aware and language-aware title / description / canonical metadata.
   - Updates EN / ES metadata after React loads.

6. src/i18n/LanguageContext.tsx
   - It already updated <html lang="en|es"> when switching language.
   - Kept as-is because it was already correct.

7. scripts/postbuild-seo.mjs

8. package.json
   - npm run build now runs the SEO post-build step automatically.
